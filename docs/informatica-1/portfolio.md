Informática I.

Tutoriales para preparar una cuenta de GitHub y publicar un portfolio creado con MkDocs Material.

## Materiales disponibles

<div class="grid cards" markdown>

-   **👤 Preparar la cuenta de GitHub**

    ---

    Creación de la cuenta desde casa, verificación del correo y localización del nombre de usuario y la dirección `noreply`.

    [Descargar tutorial](materiales/portfolio/preparar-cuenta-github.pdf){ .md-button .md-button--primary }

-   **🔑 Crear y utilizar un token de GitHub**

    ---

    Configuración de un token con acceso al repositorio para subir cambios y publicar la web desde la terminal.

    [Descargar tutorial](materiales/portfolio/crear-token-github.pdf){ .md-button }

-   **🚀 Publicar el portfolio**

    ---

    Publicación del repositorio, despliegue con MkDocs Material y activación de GitHub Pages.

    [Descargar tutorial](materiales/portfolio/publicar-portfolio-mkdocs-github-pages.pdf){ .md-button }

</div>

## Orden recomendado

1. Prepara y verifica tu cuenta de GitHub.
2. Configura el acceso al repositorio siguiendo el tutorial del token.
3. Publica el portfolio y comprueba el resultado en GitHub Pages.

!!! warning "Protege tus credenciales"

    No compartas tu contraseña ni el token de GitHub. No los guardes dentro de los archivos del portfolio ni del repositorio.
