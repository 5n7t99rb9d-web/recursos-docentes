# Aplicaciones y herramientas

Herramientas de consulta y trabajo para acompañar la observación de muestras y el estudio de Geología.

## Identificador de rocas

Aplicación de reconocimiento macroscópico basada en la colección de las prácticas 2–5. Observa la muestra y responde a las preguntas para recorrer la clave de identificación.

[Abrir identificador de rocas](apps/identificador-rocas/index.html){ .md-button .md-button--primary }

Incluye:

- **Clave de identificación** con respuestas Sí/No y ayudas sobre qué observar.
- **Calculadora Streckeisen QAPF** para los campos de clasificación trabajados en las prácticas.
- **Catálogo de rocas** con criterios de comprobación y límites de identificación.
- **Glosario buscable** de términos geológicos.

Funciona sin cuenta y conserva el recorrido en el navegador. Se abre en una página propia para disponer de todo el espacio de trabajo.

!!! info "Observa la muestra antes de responder"

    La aplicación guía la identificación mediante rasgos observables; no reconoce fotografías automáticamente. Está adaptada a la colección de las prácticas y algunos resultados necesitan pruebas de ácido, dureza o contraste con el profesor.
